# Большая перемена

«Большая перемена» — симулятор школьной столовой от первого лица команды «Интеграл» (Талант ID 55615). Проект для блока программирования НТО 2026/2027. Движок Godot 4.5.2, GDScript и рендерер GL Compatibility.

## Запуск из исходников

1. Откройте `game/project.godot` в Godot 4.5.2 и запустите проект.
2. Начните смену. Управление мышью. Если нужно, откройте «Как играть» на титуле.

Между переменами можно менять цены и планировать поставки. Начните готовить, позвоните в звонок и выдайте гостю готовое блюдо, которое соответствует его выбору и бюджету. Итог смены показывает результат обслуживания и финансовый результат.

## Где находятся правила и данные

- `game/main.gd` принимает ввод, запускает действия модели и обновляет интерфейс.
- `game/model.gd` ведёт состояние смены и применяет правила готовки, поставок и продажи.
- `game/room.gd` строит 3D-комнату и отображает гостей и блюда.
- `game/data.json` содержит базовые ингредиенты, блюда и заказы для трёх перемен.
- `configs/` содержит базовую, граничную и расширенную конфигурации для демонстрации.

## Демонстрация расширения через данные

Запуск из клонированной папки. В командах `godot` — исполняемый файл Godot 4.5.2 или путь к нему.

```powershell
$config = (Resolve-Path '.\configs\extended.json').Path
godot --path game -- "--config=$config"
```

В `extended.json` добавлена одна запись `[3,0,99]` в конец `waves[0].orders`. Это новый заказ на булочку с кашей на замену и бюджетом 99 ₽. В той же сборке общее число гостей вырастает с 24 до 25. Саша приходит через 150 секунд после открытия первой перемены. `boundary.json` задаёт нулевой стартовый запас молока для проверки контролируемого отказа готовки и восстановления после поставки.

## Автоматические проверки

```powershell
godot --headless --path game --script res://tests.gd
```

Тесты проверяют центральный цикл, целостность операций и полный автоматический маршрут смены.
